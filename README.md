# 운암초 함박꽃북토리 · 도서관 활동 안내

공개 주소: https://xptmxmdyddlqslekd.github.io/8310/

## 내용 고치는 법

1. 이 폴더의 **admin.html**을 크롬이나 엣지로 엽니다.
2. **📁 사이트 폴더 연결**을 누르고 이 폴더(8310)를 선택합니다.
3. 고친 뒤 **💾 저장**을 누릅니다.
4. GitHub Desktop에서 **Commit to main**을 누르고 **Push origin**을 누릅니다. 1~2분 뒤 사이트에 반영됩니다.

자세한 사용법과 새 학년도 체크리스트는 admin.html의 **사용법** 메뉴에 있습니다.

## 파일 구성

| 파일 | 내용 | 직접 수정 |
|---|---|---|
| `index.html` | 사이트 화면(디자인·기능) | 하지 않음 |
| `admin.html` | 관리 화면 | 하지 않음 |
| `data/site.js` | 문구·링크·사례·사진 목록 | admin.html에서 |
| `data/lectures.js` | 작가와의 만남 강연 목록 | admin.html에서 |
| `data/readings.js` | 낭독극 작품 목록 | admin.html에서 |
| `data/onchaek.js` | 온책읽기 도서 목록 | admin.html에서 |
| `images/` | 사례 사진 | admin.html에서 추가 |
| `책을_읽어주는_사람들_소개.pdf` | 낭독극 단체 소개자료 | 파일 교체 |
